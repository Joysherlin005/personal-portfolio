# Personal Portfolio Website

A responsive personal portfolio starter created for the Full Stack Development assignment. It uses semantic HTML5, custom CSS3, Bootstrap 5, and vanilla JavaScript (ES6+).

## Features

- Semantic sections: Home, About, Skills, Projects, Education, Contact
- Responsive layout using Bootstrap grid, Flexbox, CSS Grid, and media queries
- Bootstrap navbar and form components
- Dark/light theme toggle
- Project category filters
- Client-side contact form validation with inline error messages and success feedback
- Accessible labels, skip link, keyboard-friendly buttons, `aria-live` feedback, and reduced-motion support
- Responsive navigation and active section highlighting

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Internet access is needed for Bootstrap CDN and Google Fonts. The page still has custom styling if fonts fail to load.

You can also use the **Live Server** extension in Visual Studio Code.

## Before submission: personalise these items

1. Replace the sample email `hello@example.com` in `index.html` and `script.js` with your real email.
2. Update the GitHub and LinkedIn links in the hero section.
3. Replace the sample project descriptions with your own completed projects and add working repository/demo links.
4. Check the education dates and update them if needed.
5. Add your own profile photo if desired; the current hero artwork is CSS-created.
6. Test on desktop and mobile and take screenshots for your report.

## Contact form note

The form performs client-side validation and opens the visitor's default email app using a `mailto:` link. It does not store submissions or send messages directly from a server. A real production contact form needs a backend or a form service.

## Suggested GitHub submission

Create a public repository named `personal-portfolio`, upload `index.html`, `style.css`, `script.js`, and `README.md`, then submit the repository URL. GitHub Pages can be enabled from **Settings → Pages → Deploy from a branch → main → / (root)**.
